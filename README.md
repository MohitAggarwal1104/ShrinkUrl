# LinkLite — MERN URL Shortener

A full-stack URL shortener built with MongoDB, Express, React, and Node.js.

## Requirements implemented
1. Register, log in, and log out (JWT authentication).
2. Shorten a long URL.
3. View click counts for each shortened link.
4. Generate a QR code for each short URL.
5. Check custom aliases in real time and show whether the alias is available or already taken.

## Run locally

### 1. Start MongoDB
Use a local MongoDB instance or a MongoDB Atlas connection string.

### 2. Configure the backend
```bash
cd server
cp .env.example .env
```
Edit `.env` and set `MONGODB_URI` and a long random `JWT_SECRET`.

### 3. Install and run the backend
```bash
npm install
npm run dev
```
The API runs at `http://localhost:5000`.

### 4. Install and run the frontend in a second terminal
```bash
cd client
npm install
npm run dev
```
Open the URL printed by Vite, usually `http://localhost:5173`.

## API overview
- `POST /api/auth/register` — create account
- `POST /api/auth/login` — log in
- `GET /api/auth/me` — current user
- `GET /api/urls/check-alias?alias=my-link` — check alias availability
- `POST /api/urls` — create short link
- `GET /api/urls/my` — list current user's links and click counts
- `DELETE /api/urls/:id` — delete a link
- `GET /:code` — redirect to the destination and increment clicks

## Notes
- Short links are served from the backend origin, e.g. `http://localhost:5000/abc123`.
- QR codes are generated by the frontend from each short URL using `qrcode.react`.
- Alias checks are debounced to avoid sending a request on every keystroke.
- For production, serve the frontend and API over HTTPS, configure CORS for your deployed frontend, use secure cookies or carefully protect token storage, add rate limiting, and consider URL safety checks.
